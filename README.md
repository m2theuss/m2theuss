## Como penso software

- **Código que dá para manter:** nomes claros, responsabilidades bem definidas e complexidade proporcional ao problema.
- **Integração confiável:** contratos de API explícitos, validação de entrada e tratamento consistente de erros.
- **Entrega reproduzível:** documentação de execução, configuração fora do código e automação de verificações sempre que fizer sentido.
- **Decisões explicáveis:** prefiro entender e conseguir justificar uma solução a apenas fazê-la funcionar.
